# PythonBot

## About

This repo contains an Retrieval Augmented Generation (RAG) Discord Bot.
The goal of this project was to create and provide a prototype platform to test each module for another project.

It use the current working directory as its knowledge base for the context in bot responses. 
When the main Bot.py is run it will collect the files in its knowledge base and begin embedding them for use at context with the Prompt (Which is essentially a textual role play that personalizes the bot).

The bot can be given highly customizable information, and given a personality on how to act. 

No setup provided as this repo is not for distribution, but rather education purposes in how such a program and platform functions.
